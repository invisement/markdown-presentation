# Tiptap Editor Module

A headless, modern WYSIWYG editor for Markdown presentations, built on Tiptap and ProseMirror.

## Requirements

- **Markdown Support**: Seamless conversion between Markdown strings and Tiptap's JSON/HTML state.
- **Modern UI**: A premium, "wow" aesthetic using Vanilla CSS, following the project's design standards.
- **Modular ESM**: Zero-build workflow using native ESM imports from JSDelivr.
- **Barebone Foundation**: Standard editor functionality (Bold, Italic, Lists, Headings) to replace legacy editors.
- **Husk Integration**: Compatible with the project's Deno-based development and lazy-loading architecture.
- **Responsive Design**: Adapts to different screen sizes for editing on the go.

## Development

Run the local dev server to see the editor in isolation:

```bash
deno task dev
```
